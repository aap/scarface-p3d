# names/rendercore.txt (other agent); lines here that would collide are commented out.

# writes vtable 0x0073819c), not a PlugInRenderable -- 0x00464f00 is the PlugIn one.
# Names without a trailing " ?" are verified from disassembly or from MSVC RTTI
# (??_R4<Class>@renderer@@6B@ immediately preceding every vtable).
# Names ending in " ?" are guesses.
# '#' lines carry struct layouts as: offset type name
